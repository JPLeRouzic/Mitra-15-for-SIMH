; ================================================================
; MITRA-15 SIMH ADDRESSING MODE & INSTRUCTION smoke test
; ================================================================
;
; This test systematically exercises instructions across ALL valid 
; addressing modes: DL, DG, IL, IGX, ILX, P, PX, RP, RM, IL(br), IG(br).
; Each test runs, asserts the expected result, and continues.
; If any assertion fails, SIMH stops immediately (bug found).
; If all tests pass, a success message is printed at the end.
;
; Memory map used by this test:
;   0000-003F   General/Common Data (G = 0000)
;   0040-004F   General/common data, used when G = 0000
;   0040-007F   DG Data & IGX Pointers
;   0080-00BF   IG Pointers & Branch Targets
;   0100-01FF   Test code
;   0180-018F   CDS/context area for CSV/RSV tests
;   0220-0227   Floating-point operands
;   0230-0237   Floating-point/string result area
;   0240-024F   TRS translation table area
;   0400-04FF   Local Data Segment (L = 0400)
;   0500-05FF   IL & ILX Pointers/Data
;   0600-06FF   String / FP / TRS / CDS
;
; Register bases used for most tests:
;   L = 0400 (or 0200 depending on the test block)
;   G = 0000
;
; This makes DL addressing access 0400+displacement.
; DG addressing accesses 0000+displacement.
; LEA with G=0000 returns the effective address directly.
;
; ================================================================
